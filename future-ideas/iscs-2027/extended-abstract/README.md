# ISCS 2027 extended-abstract package

Working title: **When Observation Choices Resemble Dynamics in AI Conversation Archives**.

This is a methodological synthesis for discussion. It connects exact growth
expectations under fixed-graph revelation with a quantified change in a
user–assistant forecasting contrast under different information boundaries.
It combines attributed prior work with exposed development evidence. It is not
a new independent empirical paper or a validated theory of cognition.
