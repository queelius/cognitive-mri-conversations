## Independent review and corrections

An independent read-only code/scientific reviewer examined all four check families, source/formula correspondence, grouping, uncertainty, saved results and interpretations. Two material issues changed analyses; both are now corrected and regression-tested. The reviewer reran the corrected public 25-test suite and selection-sensitive 11-test suite, checked their hashes, and found no remaining material issue in the reviewed scope. This is an internal technical review, not peer review.

1. **Dependency links severed by eligibility filtering.** Public grouping originally followed the English filter. A non-English record could connect two eligible records by IP/template, leaving three known full-source components across the split. The correction builds components over all 2,000 acquired records before every eligibility filter, then takes one eligible representative. Four excluded-bridge unit fixtures and an independently reconstructed full-source integration check first failed, then passed. Final sample is 406 components, 245 development/161 evaluation; all paired role intervals include zero. Known links outside the acquired universe remain unobserved. The grouping code does not verify persons.
2. **Fixed-loss rather than selection-sensitive uncertainty.** The original prefix bootstrap held twelve LOOCV losses fixed. The new sensitivity reruns selection inside each resample and excludes all duplicates of the held-out identity. Point gain remains .017660; the interval changes from [.004829,.033807] to **[−.001224,.034807]**. Original JSON is unchanged, and the later result is separately pinned. The reviewer result was known before the addendum, which is explicitly a post-review sensitivity, not preregistration.
3. **Serialized missing label.** The public implementation initially accepted a string `None` as a class. It now normalizes the missing sentinel at index construction and excludes missing labels structurally. Superseded output and a regression test are preserved.
4. **WordPiece chunk round trip.** Decoding fixed token-ID blocks and retokenizing could add 1–4 tokens. The correction slices original text by token offsets and verifies the limit. All 8,588 sampled chunks in the corrected chunk audit respected the declared 254-token bound; final-sample tests retain this check. Changed sample sizes after grouping are separately documented.
5. **Durable evidence logs.** `.log` files were ignored by existing root rules. Relevant public run/test logs were copied to includable `.txt` files and links updated; root `.gitignore` was not changed.

See [public deviations](checks/public-cross-section/DEVIATIONS.md), [selection protocol addendum](checks/dynamics/PROTOCOL.md), and preserved `results.pre-*.json` / `split-manifest.pre-*.json` artifacts. Original failed scientific hypotheses and superseded technical outputs are intentionally retained; current reports use the corrected results.

Other recorded development failures include the metric check's missing implementation/output interface tests, absent Matplotlib in the default interpreter, and an initially misnamed coverage module. They were resolved using the existing pinned environment and corrected invocation; they did not alter the exact mathematical prediction. No repeated full-data experiment was performed merely to obtain a favorable result.

## Boundaries of the conclusion

The new public role comparisons are unadjusted exploratory comparisons on a fixed early-WildChat slice; no interval establishes a decisive role effect. Private prediction uncertainty is within one author's selected conversations. The projection null is conditional on a saved extraction and finite chains. Selection-aware bootstrap uncertainty still does not account for choosing the original twelve archetypes or for cross-conversation dependence. Exact synthetic identities establish specific mathematical limits, not prevalence in natural conversation or failure of an entire external paper.

The next decision is therefore a **bounded public validity pilot**, with a temporal fallback—not a claim that a new method is established, that cognition was measured, or that a paper is ready. The [decision memo](README.md) and [next goals](NEXT-GOAL.md) specify the evidence that would change that assessment.
