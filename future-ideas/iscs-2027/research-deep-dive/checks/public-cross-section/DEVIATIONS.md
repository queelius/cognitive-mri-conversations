# Technical corrections and deviations

The source slice, eligibility thresholds, split seed, models, estimands, and resource bounds remain as frozen in PROTOCOL.md. Implementation corrections below change selected records when necessary to enforce those requirements.

- Initial dependency installation used the shell interpreter (Python 3.10) while the cached-model environment is Python 3.11. A mistaken Python 3.12 wheel also failed to import; the interpreter version was then checked and pyarrow 21.0.0 installed for Python 3.11 into this check's `.deps/`. Neither the original research environment nor original source was modified. Package downloads are separate from the protocol's record-download cap.
- A first complete run exposed the released string `"None"` in domain/intent labels. The initial parser treated that string as a category. A new unit test reproduced the problem; the parser now normalizes it to missing, as required by the frozen requirement for both substantive labels. The initial output is preserved as `results.pre-label-fix.json` and `run.pre-label-fix.txt`. Use only `results.json` for interpretation. The final split is recomputed mechanically after excluding missing labels; no performance-driven selection or parameter change was made.
- Final chunk-boundary verification found that decoding WordPiece-ID blocks and then retokenizing could increase the count beyond 254 (650 of 8,589 chunks across the full acquired content slice, maximum 258). A crafted regression test reproduced the failure. The corrected chunker preserves original text via tokenizer offsets and checks the exact span against the 254-token budget. Pre-correction output is preserved in `results.pre-chunk-fix.json` and `run.pre-chunk-fix.txt`; that correction left the sample/split and scientific parameters unchanged.
- **Grouping correction specified before rerun, 2026-10-15:** independent review found that filtering for English before connected-component construction severed IP/template bridges carried by excluded source rows. Reconstructing the full cached universe identified three components crossing the previous development/evaluation split (10, 3 and 2 selected records). The previous independence assertion and role estimates are invalid for the intended grouped estimand. Preserve them in `results.pre-leakage-fix.json`, `split-manifest.pre-leakage-fix.json`, `run.pre-leakage-fix.txt`, `tests.pre-leakage-fix.txt` and `coverage.pre-leakage-fix.txt`. Construct IP/prompt components over **all 2,000 acquired source rows**, including rows excluded by language, date, labels, duplicate-content or nonempty-role eligibility. A missing prompt contributes no prompt edge but can still contribute an IP edge. Then retain one eligible representative per full-universe component; hash all component member IDs for the split. This can change representatives and split assignments mechanically. Keep the frozen slice, filters, seed, token limits, models and uncertainty procedures. Add the three-row excluded-language bridge regression and an end-to-end assertion reconstructing components from all cached source rows. No new data or parameter search is authorized by this correction. Other shard rows lack acquired prompt content, so unseen links outside this 2,000-row universe remain a limitation.
- Logs are copied to `.txt` names so evidence is includable despite the repository's existing `*.log` ignore rule. The root ignore file is unchanged.
- **Grouping rerun outcome:** the same 2,000 source rows form 787 full-universe components; 1,020 eligible candidate rows occupy 406 components, giving 245 development and 161 evaluation representatives. All four synthetic excluded-bridge regressions failed before the fix and passed afterward. The independent full-source graph traversal also failed before the fix (three mixed-split components) and now passes both split separation and one selected representative per component. All 25 tests pass; code coverage is 99% for analysis and 84% combined. The corrected role comparisons remain inconclusive: every paired 95% interval includes zero. Only the current `results.json` and `split-manifest.json` describe the corrected grouped estimand. The source slice, configuration and original protocol hashes are unchanged.
- The first 2,000 content rows cover only April 9–10, 2023. This was discovered after the preselected acquisition, not chosen after comparing performance across periods. Generalization to later models or other collection periods is untested.
- Separate human-validation datasets were audited for access/metadata only. They were not used as a second experiment, training material, or an outcome-driven replacement for the fixed WildChat check.
